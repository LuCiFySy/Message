# Messages

A simple Android SMS/MMS messaging app.

## Features

- SMS and MMS messaging
- Scheduled messaging 
- Conversation search
- Contact picker
- Archive conversations
- Unread filtering
- Swipe to delete conversations
- Delete SMS directly from notifications
- Copy OTP directly from notifications
- Inline reply from notifications
- Delivery reports
- Message notifications
- Default SMS app support

## Requirements

- Android 8.0 (API 26) or newer
